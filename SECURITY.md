# Security policy

Faultline processes synthetic data only. Do not use real customer, employee, or regulated data in this demonstration environment.

## Credential boundary

- Local Databricks access uses OAuth user-to-machine authentication.
- The Databricks App uses its dedicated service principal and managed resource bindings.
- No personal access tokens, OAuth secrets, database passwords, workspace URLs, or generated Databricks profiles belong in Git.
- Database credentials generated by setup tooling are short-lived and passed through process environment variables only.

The app is intentionally read-only. It receives `CAN_USE` on one SQL warehouse and `SELECT` on the four pipeline tables it displays.

## Reporting

If you find a vulnerability, do not include credentials or sensitive workspace information in a public issue. Use GitHub's private vulnerability reporting for this repository when available.
